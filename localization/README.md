# French localization workflow

The US ROM remains the source of game assets. The French ROM is used only to
extract the France French dialogue and font. Do not put ROMs in a release.

`assets/build_localized.py` automates extraction and builds one resource bundle
with English, France French, familiar Quebec French, Beauce slang, and Quebec
French with sacres:

```powershell
python assets/build_localized.py --extract-only
python assets/build_localized.py
python assets/validate_localization.py
python assets/preview_localization.py
```

By default, the helper uses `zelda3.sfc` at the repository root and
`roms/Legend_of_Zelda_The_A_Link_to_the_Past_(Fr).sfc`. Pass `--us-rom` and
`--fr-rom` to use other locations; relative paths are resolved from the
repository root. The extraction step writes generated
`assets/dialogue_fr.txt` and `assets/font_fr.png`; it never changes
`dialogue_fr_c.txt`.

The familiar Quebec adaptation belongs in `localization/dialogue_fr_c.txt`;
the Beauce-flavored version is in `localization/dialogue_fr_beauce.txt`; the
sacres version is in `localization/dialogue_fr_ca_sacres.txt`. They use the
same numbered message format as the France source. Preserve bracketed game commands such as `[Name]`,
`[Number 00]`, and `[Waitkey]` exactly. Proper names and item/place names keep
their France-source spelling. The compiler reads all three Quebec files
directly and reuses the France font unless a locale-specific font is added later.

The root `zelda3_assets.dat` is regenerated by the helper. Use
`python assets/build_localized.py --no-extract` for later rebuilds after editing
any Quebec text, as long as the extracted French dialogue and font are
present. The validator checks all 397 message IDs, ordered game command tags,
supported French glyphs, and approximate rendered line widths. The preview is
an offline five-column HTML page with search, locale toggles, and missing/long-
text filters. At startup, choose English, France French, familiar Quebec French,
Beauce slang, or Quebec French with sacres; the selection is stored in
`zelda3.user.ini` as the default.

## Unofficial fan adaptations

These Quebec dialogue files are unofficial fan adaptations and are not endorsed
by Nintendo. Nintendo retains the rights to Zelda and the original game text.
The repository's MIT license covers its original code and tools; it does not
grant rights to Nintendo's game content.
